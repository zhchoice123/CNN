# 深度学习与计算机视觉 · 双语学习站 开发计划

## 1. 目标

以本目录 30 本 PDF（及已生成的 `tts_scripts/` 导读稿）为素材，把内容**按主题合并**成一套章节化课程，做成一个离线可用的 HTML + CSS + JS 学习站。每章包含三类内容：

| 模块 | 内容 |
|---|---|
| **学习 Learn** | 分节讲解 → 要点细化 → 代码验证（真实运行过的 Python 代码 + 运行输出）→ 出处 |
| **例题 Examples** | 题目 → 分步解析（可逐步展开）→ 答案，部分附代码 |
| **测验 Quiz** | 选择题、判断题、填空题、英文阅读理解（附朗读音频） |
| **词汇 Vocabulary** | 核心术语中英互译：英文、中文、英文释义、中文释义、例句，每个词条有英文和中文 mp3 读音 |
| **闪卡 Flashcards** | 词汇卡 + 概念卡，可翻面、发音、按掌握度复习（Leitner 盒子） |

## 3. 每章内容规格

- 学习：4 节，每节含讲解（含公式）、3–5 条要点细化、可运行代码（numpy 实现，构建时真实执行并记录输出）、出处
- 例题：3 道，带分步解析
- 测验：选择 6 题、判断 5 题、填空 4 题、阅读理解 1 篇（英文原创短文 + 3 题 + 朗读 mp3）
- 词汇：12–14 个核心术语（中英互译 + 释义 + 例句 + 中英 mp3）
- 闪卡：全部词汇卡 + 4 张概念卡

## 4. 技术方案

```
study_site/
├── index.html                单页应用（hash 路由，file:// 直接打开即可）
├── assets/css/style.css      响应式布局、亮/暗主题
├── assets/js/app.js          路由、渲染、测验引擎、闪卡（Leitner）、进度（localStorage）、音频
├── assets/js/course-data.js  构建产物：全部课程数据
├── assets/vendor/            KaTeX（公式）、highlight.js（代码高亮），本地化，离线可用
├── content/chXX.py           章节内容源文件（Python 字典，原始字符串便于写公式）
├── code/chXX_*.py            代码验证用的可运行脚本
├── audio/                    edge-tts 生成的 mp3（词汇中英读音、阅读理解朗读）
└── tools/
    ├── build.py              汇总内容 → 运行代码并记录输出 → 校验题目 → 生成 course-data.js
    └── gen_audio.py          调用本地 edge-tts（与 ~/Documents/EdgeTtsProject 相同方案）生成 mp3
```

- 运行环境：`/Library/Frameworks/Python.framework/Versions/3.13/bin/python3`（自带 numpy 与 edge_tts）
- 语音：英文 `en-US-AriaNeural`，中文 `zh-CN-XiaoxiaoNeural`；已存在的 mp3 跳过，支持增量生成
- 代码区可选“在浏览器运行”（按需从 CDN 加载 Pyodide；离线时显示构建时验证过的输出）

## 5. 开发步骤

1. 搭骨架：目录、下载 vendor 依赖、index.html、样式、app.js
2. 构建工具：build.py（内容汇总、代码执行、题目校验）、gen_audio.py
3. 先完成第 08 章（CNN，本项目核心）作为样板，并在浏览器里验证全部功能
4. 依次编写其余 15 章内容和代码
5. 全量构建：执行全部代码、生成全部 mp3
6. 浏览器回归测试：路由、测验判分、闪卡、音频、公式、暗色模式、手机宽度
7. 写 README（使用与重新构建方法）
