# 验收清单：MacBook Pro（M3 Pro）与 Windows（RTX 3060）

每台机器各走一遍。前三项是自动验收，后面是手工检查。勾选完把结果截图或记在下面的“记录”里。

## 0. 准备

| | macOS（Apple 芯片） | Windows（RTX 3060） |
|---|---|---|
| Python | 已有 3.13 | 安装 Python 3.13（python.org，勾选 “Add to PATH”） |
| 显卡驱动 | — | NVIDIA 驱动 ≥ 560（`nvidia-smi` 能看到 RTX 3060） |
| 安装 | `python3 lab/setup.py` | 双击 `lab\setup_windows.bat`（或 `py -3.13 lab\setup.py`） |
| 数据集 | 已下载在 `datasets/` | 拷贝 Mac 上的 `datasets/` 整个目录过去，或 `python lab/setup.py --datasets` |
| 启动 | `bash lab/start.sh` | 双击 `lab\start_windows.bat` |

- [ ] 安装脚本最后打印：macOS `Apple MPS 可用: True`；Windows `CUDA 可用: True` 且硬件里显示 `RTX 3060`

## 2. 训练实验室

- [ ] 打开 <http://localhost:8766/#/lab>，顶部显示 PyTorch 版本和 `Apple GPU（MPS）可用` / CUDA 可用

## 4. 代码练习

- [ ] `#/practice` 列出 6 篇，每篇显示 L1–L4 进度
- [ ] L1：选错显示 ✖，选对显示答案和解析；答错的题出现在“错题本”，点“重做”回到练习
- [ ] L2：`28 * 28`、`criterion( logits , yb )` 这类等价写法判为正确
- [ ] L3：直接点“运行全部检查”→ 在第 1 步失败并给出中文解释；补完第 1 步后“运行到当前步骤”→ 第 1 步通过
- [ ] L3：故意删掉 `loss.backward()` → 在“训练循环”一步失败，提示准确率过低
- [ ] L3：故意写错缩进 → 报 `IndentationError`，左侧行号标红、该行高亮
- [ ] L4：从空白模板写出完整代码 → 全部通过 → “用你的代码在实验室完整训练” → 实验室里出现这次运行和曲线
- [ ] 刷新页面：草稿、进度都还在
- [ ] 章节页（如第 6 章、第 8 章）底部出现“✍️ 动手练习”入口；代码库里搜“练习”能看到 6 篇答案和“分步练习这段代码”按钮
